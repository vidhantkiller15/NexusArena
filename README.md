# Nexus Performante Arena

Lightweight **performance command center** for Windows.  
Neon HUD · built-in FPS · game vault · boost · focus mute · macros · updates · music.

**Launch:** double-click **`start.bat`**

---

## Music (mp3player.py)

Pulse uses your **`mp3player.py`** stack — **not ffmpeg**:

| Source | Backend |
|--------|---------|
| Local file / PC search | **pygame** |
| Song name / YouTube link | **yt-dlp** stream + **VLC** (`python-vlc`) |

Install once:
```bat
pip install pygame python-vlc yt-dlp
```
Also install [VLC media player](https://www.videolan.org/) (the app, not just the pip package).
